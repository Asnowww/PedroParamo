# 佩德罗·巴拉莫

改编自胡安·鲁尔福小说《佩德罗·巴拉莫》的交互叙事 demo。Godot 4。

---

一个人受母亲临终之托，去一座叫科马拉的村子找他从未见过的父亲。带他下山的赶驴人说，
那个人也是自己的父亲——顺口又说，他早就死了。

村里家家开着门，门里黑得像井。给他开门的女人说，是你母亲通知我你要来的；
可他的母亲，七天前就已入土。

走到全书一半，他自己也死了。后半本，他躺在坟里，听整座村庄的亡魂说话。

## 为什么值得做成游戏

原著由六十个打乱时序的碎片拼成，读者的阅读过程本身就是在拼图。这个 demo 不打算把碎片捋直，
而是把**拼碎片这件事本身**交到玩家手里。

**祭坛拼图。** 每段记忆是一张墨西哥 Lotería 彩票牌，玩家把它们按事情发生的先后摆上亡灵节祭坛。
摆对一张，亮一支蜡烛；拿走，蜡烛就灭。玩家不是在选择剧情，而是在重建因果。

**坟中倾听。** 死后画面几乎全黑。声音散在四周，左右转动耳朵去对准它，对住不动，
话才会一句一句浮出来——地底下不是安静，是所有的时间都在同时说话。

**生死笔记。** 游戏从头到尾不说谁是活人、谁是鬼。玩家自己给遇到的二十六个人做判断，
而系统**从不告诉你对错**。等你终于知道答案的时候，会想回头看看自己都写了些什么。

**理解度结局。** 结局事件永远只有一个（原著的结局不该被改动），变的是终章旁白揭示到哪一层。
你听全了多少，科马拉就为你亮起多少。

## 三条视觉线

**照片是已经发生的事，绘画是还活着的记忆。** 三条叙事线因此用三种媒介，而不只是三种色调：

| | 媒介 | 语义 |
|---|---|---|
| 现在（鬼村） | 仿鲁尔福摄影的黑白影像 | 照片即死亡的证据——鲁尔福本人也是摄影师 |
| 回忆（活着的科马拉） | 墨西哥壁画运动（Rivera / Orozco） | 记忆是主观的、被体温染过的 |
| 苏萨娜 | 蓝晒（cyanotype） | 全片唯一的冷色域，她的意象全是水 |

死亡与卡牌统一用波萨达（José Guadalupe Posada）的木刻版画语言。
民间艺术全部下沉到交互层：祭坛是拼图板，米拉格罗斯是图标，骷髅诗是章节页。

206 张图逐张手写提示词生成，再过同一道后期管线焊成一体——所以它们看起来像同一双眼睛拍的。

## 跑起来

需要 [Godot 4.7+](https://godotengine.org/)。

```bash
python tools/postprocess.py    # 生成成品图：分线调色 + 统一纸纹颗粒（需 pillow）
godot --path game              # 或用 Godot 编辑器打开 game/
```

`tools/gen_audio.py` 会合成占位音效（需 numpy）；正式音效待替换。

## 仓库里有什么

- `game/data/fragments/*.json` —— 剧本。每个碎片是一串操作码（换景 / 台词 / 拾卡 / 拼图 / 倾听 / 跳转），
  `game/scripts/story.gd` 是通读它们的播放器。改剧情不用碰代码。
- `art/backgrounds/` —— 206 张原图。`art/fragments_map.md` 和 `art/manifest.csv` 是碎片、剧情、卡牌、
  资产之间的对照表，人读一份、机读一份。
- `tools/` —— 后期管线、占位音频、骷髅诗草稿。
- `PLAN.md` —— 从工程奠基到打包的里程碑记录。

## 进度

六十个碎片全部贯通，八处拼图，六十一张可收集卡，三层结局。
