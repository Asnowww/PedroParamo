# 佩德罗·巴拉莫 · 交互叙事 demo

改编自胡安·鲁尔福（Juan Rulfo）同名小说的视觉小说 / 交互叙事 demo。用 Godot 4 制作。

> **这是一个非商业的个人学习项目。** 原著与中译本著作权归权利人所有；本仓库不包含原著文本，
> 剧本为面向游戏的再创作。若权利人认为不妥，请开 issue，我会立即处理。

## 它是什么

原著是一部由六十个乱序碎片拼成的小说：一个人去死人的村庄找父亲，走到一半发现自己也死了，
后半本躺在坟里听整座村庄的亡魂说话。

这个 demo 不打算把碎片捋直，而是把**"拼碎片"本身做成玩法**：

- **祭坛拼图** —— 记忆做成墨西哥 Lotería 彩票牌，玩家把它们按发生的先后摆上亡灵节祭坛，摆对一张亮一支蜡烛
- **坟中倾听** —— 死后画面几乎全黑，靠转动耳朵对准声源（位置音频）把亡魂的话一句句"听"出来
- **生死笔记** —— 全程不告诉你谁是活人谁是鬼，玩家自己给二十六个人做判断，**游戏从不验证对错**
- **理解度结局** —— 结局事件唯一（忠于原著），你拾得的碎片越多，终章揭示的因果链越深

## 运行

需要 [Godot 4.7+](https://godotengine.org/)。

```bash
# 1) 生成成品图（三条视觉线各自调色 + 统一纸纹颗粒）
python tools/postprocess.py        # 需要 pillow

# 2) 用 Godot 打开 game/ 目录，或命令行运行
godot --path game
```

`tools/gen_audio.py`（需 numpy）会生成占位音效，正式音效待替换。

## 目录

| 路径 | 内容 |
|---|---|
| `game/` | Godot 工程：`data/fragments/*.json` 是剧本（自研操作码），`scripts/story.gd` 是播放器 |
| `art/backgrounds/` | 206 张美术原图（AI 生成，见下） |
| `art/fragments_map.md` | 碎片 × 剧情 × 卡牌 × 资产对照表 |
| `art/manifest.csv` | 同上，引擎/脚本用的机读版 |
| `tools/` | 后期管线、占位音频、骷髅诗草稿 |
| `PLAN.md` | 开发里程碑 M0–M7 |

## 美术

三条叙事线用三种媒介区分——**照片=已成事实的死亡，绘画=活着的记忆，蓝晒=苏萨娜**：

- 现在线：仿胡安·鲁尔福摄影的黑白影像（他本人也是摄影师）
- 回忆线：墨西哥壁画运动风格（Rivera / Orozco）
- 苏萨娜线：蓝晒（cyanotype）工艺
- 死亡与卡牌：波萨达（Posada）木刻版画

全部由 AI 图像生成，逐张手写提示词，再过同一道后期管线（`tools/postprocess.py`）焊成一体。
